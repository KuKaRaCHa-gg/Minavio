# Modèle arnndn (RNNoise)

`bd.rnnn` = "beguiling-drafter" (2018-08-30) du dépôt https://github.com/GregorR/rnnoise-models :
bruit d'enregistrement (ventilateur, clavier, souffle) sur signal "voix". Utilisé par le filtre
FFmpeg `arnndn=m=...`.
